# NurseStart Lab｜新進護理師學習基地

這個專案提供新進護理師給藥安全、臨床推理與病房互動教學試玩。

## 教學範圍

- Aspirin、Metformin、Famotidine、Acetaminophen 四種核心藥物
- 217 床情境對話分支與臨床判斷
- 219 床輸液部位評估及呼叫鈴事件
- Clindamycin 變更 Cefepime，查閱培養報告與藥敏資訊
- 無菌抽藥與處置回顧

此網站為教學模擬，所有病人資訊皆為虛構／去識別化情境；不應放入任何真實病人個資。醫囑、處置及評分內容須先經機構內臨床教師及藥師審核，且試玩結果不能直接代表 EPA 信賴程度。
